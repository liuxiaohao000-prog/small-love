# v8 国漫角色重做版

本分支重做角色头脸、关节封口、表情与动作，并保留离线回退模型。

- 立体头脸：三维眼球、眼睑、鼻体和多套嘴型；
- 闭合网格：发束、披帛和可见关节全部封口；
- 穿模治理：刘海/脸颊、后发/肩背、袖子/前臂、裙摆/腿部留安全距离；
- 动作：Idle、Walk、Run、Pet 和任务动作连续播放并加入次级摆动；
- 表情：人物与小狗均支持眨眼、开心、张嘴和互动表情；
- 资源：4K 服装/头发纹理、2K 皮肤/毛发与法线纹理；
- 目标设备：OnePlus 12，运行内存目标 350–700MB，上限 1000MB。

完整方案见交付包中的 `V8_REDESIGN_PLAN.md`。
