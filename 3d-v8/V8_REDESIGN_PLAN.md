# 小爱庄园 3D — v8 国漫角色资产重做方案

## 1. 目标与验收口径

本次不再在 v7 的贴片脸和分段低模上继续修补，而是重做角色头脸、可见关节封口、表情结构和动作表现。目标设备为 OnePlus 12，允许峰值运行内存不超过 1000 MB；实际目标控制在 350–700 MB，避免 WebView/WebGL 因无意义堆资源而崩溃。

验收必须同时满足：

- 正面和侧面观察时，脸部具有明确体积，眼睛、鼻子、嘴巴不再是贴在头上的平面图片。
- 头部、颈部、肩肘、袖口、手腕、髋膝和裙摆不出现可见破面、黑缝或孔洞。
- 刘海不穿额头，侧发不穿脸颊，后发不穿肩背，袖子不穿前臂，裙摆不穿腿。
- Idle、Walk、Run、Pet 与六类任务动作能连续播放，脚步、骨盆、脊柱、肩肘和次级摆动协调。
- 人物和小狗均具有可辨识表情，而不是仅靠整体缩放模拟。
- Android WebView 离线加载成功，APK 通过 ZIP、资源、JavaScript、GLB 和 v2 签名检查。

## 2. 人物建模重做

### 2.1 头脸

- 使用闭合高密度头模，重新塑造额头、颧部、眼眶、面中、下颌和下巴体积。
- 眼睛改为独立三维眼球：眼白、虹膜、瞳孔、高光、上眼睑和下眼睑。
- 鼻子改为鼻梁、鼻尖和鼻翼三维结构。
- 嘴部改为闭合三维曲线，预置中性、微笑、张嘴和惊讶四种造型节点。
- 耳朵增加外耳和内耳结构；下颌与颈部增加遮缝连接。
- 腮红使用贴合面部曲率的轻量三维片体，不再使用大面积透明平面。

### 2.2 头发

- 后发帽、发冠、刘海、侧发、后发束分层布置。
- 刘海仅覆盖额头上缘，不下穿眼球；侧发与脸颊保留安全间距；后发避开肩背。
- 发束使用闭合管状网格并加入根部、中段、发尾三级摆动。

### 2.3 身体与服装

- 肩、肘、手腕、髋、膝增加闭合关节覆盖体，消除分段模型黑缝。
- 袖口与前臂、裙腰与躯干、鞋口与脚踝采用重叠封口。
- 手部增加手掌和五指轮廓；鞋底和鞋面分别建模。
- 内裙、外裙、披帛与腿部重新拉开空间，优先保证动作中不穿模。

## 3. 表情系统

人物至少包含：自然眨眼、微笑、开心张嘴、惊讶、委屈、专注、抚摸小狗和任务完成表情。控制对象包括眼球、上下眼睑、眉毛、中性嘴、微笑嘴、张嘴和惊讶嘴。

小狗至少包含：眨眼、开心眯眼、张嘴、吐舌、歪头、耳朵抖动、摇尾和被抚摸时身体下压。

## 4. 动作系统

- Walk：脚跟落地—全脚掌支撑—脚尖离地；膝盖缓冲；骨盆左右移重；脊柱和肩部反向摆动。
- Run：更大的腾空和落地缓冲；身体前倾；手臂加速摆动；头部稳定补偿。
- Idle：呼吸、视线、眨眼、细微重心切换、头发和衣摆缓慢摆动。
- Pet/任务：手臂动作之外增加脊柱前倾、头部注视和对应面部表演。
- 头发、袖子、裙摆和披帛采用延迟相位的次级动画，避免刚体机器人感。

## 5. 材质与渲染

- 4K 头发、蓝色织锦和玫红织锦纹理；2K 皮肤、毛发和法线纹理。
- 皮肤不使用高强度法线，避免面部发脏；眼睛和嘴部使用不受灯光污染的安全材质。
- 禁用反向壳黑色描边；使用正面补光、轮廓光和接触阴影形成国漫手游风格。
- 自适应像素比上限保持 2.0，纹理各向异性提高但不超过设备能力。

## 6. 美术与工程审查

### 美术审查

- 正面、四分之三和侧面轮廓。
- 五官体积与比例。
- 头发和服装层次。
- 静态破面、孔洞、黑缝和明显穿插。
- Idle、Walk、Run、Pet 和任务关键帧穿模。
- 人物与小狗表情可读性。

### 工程审查

- GLB 2.0 结构、Accessor 范围、索引合法性、动画轨道和节点引用。
- JavaScript 在目标 WebView 兼容语法范围内。
- APK 必需资源、ZIP 对齐、v2 签名和 SHA-256。
- 资源预算和运行时降级路径。
